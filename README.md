# 또박또박 받아쓰기 🐻✏️

초등학교 1학년을 위한 국어 받아쓰기 놀이 프로그램입니다.
조사, ㅐ/ㅔ/ㅖ 구별, 띄어쓰기, 그리고 **"왜 소리와 글자가 다를까?"**를 놀이하면서 배워요.

## 실행 방법

설치할 것이 없습니다. `index.html`을 크롬, 엣지, 사파리에서 열면 됩니다.

```bash
# 태블릿이나 다른 기기에서 접속하려면 간단한 서버를 켜세요
python3 -m http.server 8000
# 그다음 http://<컴퓨터 IP>:8000 으로 접속
```

- 소리는 브라우저의 한국어 음성으로 나옵니다. 한국어 목소리가 없는 기기에서는 받아쓰기 화면의 **👀 어른용** 버튼을 눌러 어른이 읽어 주세요.
- 별과 스티커는 그 기기의 브라우저에 저장됩니다.

## 놀이 구성

| 섬 | 배우는 것 |
|---|---|
| 🎧 받아쓰기 섬 | 4단계(낱말 → 짧은 문장 → 긴 문장 → 도전). 키보드나 🧩 글자 조각으로 답하고, 틀린 까닭(소리대로 씀, ㅐ/ㅔ, 띄어쓰기)을 알려 줘요 |
| 🧩 조사 마을 | 받침이 있으면 이·을·은·과, 없으면 가·를·는·와. 글자를 조각내서 받침을 보여 줘요 |
| 🦀 ㅐㅔ 바닷가 | 짧은 팔이 안에 있으면 ㅐ(개 🐶), 밖에 있으면 ㅔ(게 🦀), 팔이 두 개면 ㅖ |
| ✂️ 띄어쓰기 숲 | "아버지가 방에 / 아버지 가방에"처럼 뜻이 바뀌는 문장을 먼저 보고, 글자 사이를 눌러 띄어 써요 |
| 🔍 소리 탐정 | [으막] → 음악. 받침 이사, 힘센 소리, 코맹맹이 소리 등 소리 바뀜 7가지 |
| 🏆 스티커북 | 별 10개마다 스티커 1장, 섬마다 최고 점수 |

자세한 기획은 [PLAN.md](PLAN.md)에 있어요.

## 파일

```
index.html      화면 틀
css/style.css   공책(밝은 화면) · 칠판(어두운 화면) 디자인
js/data.js      문제와 설명 데이터 (여기만 고치면 문제를 늘릴 수 있어요)
js/app.js       한글 조각내기, 채점, 놀이 화면
```

## 문제 추가하기

`js/data.js`에 줄을 더하면 됩니다.

```js
// 받아쓰기: t=문장, e=그림, hints=[글자, 소리, 종류]
{ t: '꽃이 예뻐요.', e: '🌷', hints: [['꽃이', '꼬치', 'yeon']] },
// 소리 탐정: w=글자, s=소리, k=종류
{ w: '음악', s: '으막', e: '🎵', k: 'yeon', tip: '음의 받침 ㅁ이 옆 칸으로 이사 갔어요.' },
```

종류: `yeon`(받침 이사) `tense`(힘센 소리) `nasal`(코맹맹이) `palatal`(ㅈ·ㅊ 변신) `h`(ㅎ 숨바꼭질) `rep`(받침 대장 7형제) `liquid`(ㄹㄹ 쌍둥이) `ae` `ye` `space`
